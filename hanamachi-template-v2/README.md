# 『花待ち通り』Webサイト テンプレート（PNG素材版）

HTML・CSS・JavaScript と **PNG素材23点** のテンプレートです。**文章はすべて「ここに入力して」に置き換え済み**です。作品タイトル（画像ロゴ）、ナビゲーション、四季名など構造上必要な語句と仮素材に関する注意書きは残しています。

## 使い方

1. `index.html` をブラウザで開くとサイトが表示されます。スマホでも見られます。
2. テキストの編集は `index.html` の `ここに入力して` を検索して、**各箇所を個別に編集**します。**一括置換すると全箇所が同じ文章になるので注意してください**。
3. 画像・ロゴ・アイコン・装飾を変更するには `assets/images/` 内の該当PNGを**同名ファイルで置換**します。推奨サイズ・使用場所は `画像差し替え一覧.csv` を参照してください。
4. サイト名を変更したい場合、テキスト部分だけでなく `logo-header.png`・`logo-hero.png`・`logo-footer.png` を変更する必要があります。すべて透過PNGです。
5. 画像の拡大表示では、ギャラリーの `src` と `data-lightbox` を両方変更してください。ギャラリーのポップアップ説明は `data-caption="ここに入力して"` を編集してください。
6. **CSSは配置・サイズ・レスポンシブ用です。** 装飾花の絵やタイトルロゴ、特徴アイコンはPNG素材ですが、ボタン・余白・カード形状等のUIはCSSです。

## フォルダ

- `index.html` — テキスト・各セクション・画像の読み込み
- `assets/css/style.css` — 配置・配色・レスポンシブ
- `assets/js/script.js` — 開閉ナビゲーション・スクロール・画像拡大
- `assets/images/*.png` — 交換可能な画像、ロゴ、装飾、アイコン
- `画像差し替え一覧.csv` — 全PNG素材の列挙・使用箇所・推奨サイズ

## 公開前の確認

- 現在は検索エンジンに公開されないように `noindex` を付けています。正式サイトになってから設定を変更してください。
- 画像は**テンプレート用仮イラスト**であり、**実際のゲーム画面ではありません**。
- 著作権表記、ゲーム制作情報、配信URL等を正式情報に差し替えてください。
- PNGの画像内に組み込まれた「花待ち通り」の文字は `index.html` から編集できません。PNG自体を差し替えてください。
- 背景イメージの有無や画像位置は `assets/css/style.css` の最後のPNG素材用CSSで調整できます。
